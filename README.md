# Linux System Cleanup GUI

Графическая утилита для очистки системы Linux с удобным интерфейсом на PyQt5.
Позволяет выборочно удалять старые snap-ревизии, неиспользуемые Flatpak-пакеты,
кеши apt, старые журналы systemd и временные файлы.

## Возможности

- **Выборочная очистка** — отмечайте только нужные пункты чекбоксами:
  - Snap: старые ревизии пакетов
  - Flatpak: неиспользуемые пакеты и их данные
  - Apt: `autoremove` + `clean`
  - Journal: журналы systemd старше 7 дней
  - Кеши `~/.cache/*` и `/var/tmp/*`
- **Асинхронная работа** — очистка выполняется в фоновом потоке, интерфейс не зависает.
- **Прогресс-бар** с текстовым статусом текущего шага.
- **Подробный лог** выполняемых команд и их вывода в реальном времени.
- **Итоги** — показывает, сколько места освобождено (или занято) и сколько свободно после очистки.
- **Подтверждение** перед удалением с перечнем выбранных действий.
- **Блокировка выбора** во время работы, чтобы избежать конфликтов.

## Требования

- Linux
- Python 3.6+
- PyQt5
- Права `sudo` (для удаления snap, apt, journal, `/var/tmp`)

### Установка зависимостей
```bash
sudo apt install python3-pyqt5
# или
pip install PyQt5
```

## Запуск
Скрипт требует прав root для выполнения системных команд, но также использует
переменные окружения пользователя (для ~/.cache), поэтому запускайте с -E:

```bash
sudo -E python3 cleanup.py
```

## Безопасность и предостережения

⚠️ ~/.cache/* и /var/tmp/* удаляются полностью — убедитесь, что там нет нужных данных.

⚠️ Удаление старых snap-ревизий может занять время и требует snapd.

⚠️ Команды выполняются через sudo — скрипт должен запускаться от пользователя с правами sudo.

⚠️ Flatpak-очистка удаляет данные неиспользуемых приложений (--delete-data).
